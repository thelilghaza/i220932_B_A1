# student-ml-api

Machine Learning Inference Service with automated Continuous Integration, Docker containerization, and automated release pipeline to GitHub Container Registry (GHCR).

## Overview
This repository contains the `student-ml-api` microservice designed for production MLOps workflows.

### Intended Architecture
- **API Framework**: Flask
- **Containerization**: Docker
- **Testing**: Pytest
- **CI/CD**: GitHub Actions
- **Container Registry**: GitHub Container Registry (GHCR)
